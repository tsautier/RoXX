# RoXX v1.1.4 Release Notes

**Release Date:** September 23, 2026
**Tag:** v1.1.4

RoXX 1.1.4 adds origin checks for cookie-authenticated mutations and WebSockets, removes RADIUS user passwords from the list API, and makes logout a POST action.

See `RELEASE_NOTES_v1.1.4.md` for upgrade requirements and verification scope.
