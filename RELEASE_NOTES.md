# RoXX v1.1.0 Release Notes

**Release Date:** September 22, 2026
**Tag:** v1.1.0

RoXX 1.1.0 delivers the completed production roadmap and replaces the shared first-run
administrator password with unique bootstrap credentials.

## Highlights

- Unique initial `superadmin` password with mandatory rotation and automatic credential-file cleanup.
- Automatic replacement of unchanged legacy `admin/admin` credentials.
- Production security profiles, readiness checks, metrics, audit export, rotating logs, and hardened services.
- Guarded Windows and Linux upgrades with readiness-based rollback.
- Standalone Windows, Linux, and macOS applications plus Debian and RPM packages.
- SHA256 manifests, SPDX SBOMs, provenance attestations, and post-upload checksum verification.

See `RELEASE_NOTES_v1.1.0.md` for the complete upgrade notice, external-validation boundaries,
and release details.
